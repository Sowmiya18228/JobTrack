\# JobTrack — Job Application Tracker



JobTrack is a web application designed to help job seekers organize and track their job applications in one place.



\## Features



\- Dashboard to view job application statistics

\- Add, edit, and delete job applications

\- Track application statuses

\- Manage interview details

\- Search and organize applications

\- Analytics dashboard

\- Responsive user interface

\- MongoDB database integration



\## Tech Stack



\*\*Frontend:\*\* React, Vite, CSS  

\*\*Backend:\*\* Node.js, Express.js  

\*\*Database:\*\* MongoDB Atlas  

\*\*Other Tools:\*\* Git, GitHub, REST API



\## Getting Started



\### 1. Clone the repository



```bash

git clone YOUR\_GITHUB\_REPOSITORY\_URL

cd JobTrack

```



\### 2. Install dependencies



```bash

npm install

```



\### 3. Configure environment variables



Create a `.env` file in the project root and configure:



```env

MONGODB\_URI=your\_mongodb\_connection\_string

PORT=5000

FRONTEND\_URL=http://localhost:5173

```



Never commit your `.env` file or share database credentials.



\### 4. Start the backend



```bash

npm run server

```



\### 5. Start the frontend



Open a second terminal in the project directory and run:



```bash

npm run dev

```



Open the local URL displayed by Vite, usually `http://localhost:5173`.



\## Production Build



